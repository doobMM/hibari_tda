# 실패 유형 A~N — 사례 상세

`MEMORY.md` 의 각 항목에 대응하는 실제 사건 기록. 색인에서 해당 유형이 걸렸을 때만 읽어라.

## A. 순환 논증 — 지표가 손실이 최적화한 양

**2026-08-13.** 위상 손실 디퓨전의 개선 지표 4개 중 **3개(밀도·cycle 프로파일·H₀ 구간 수)가
손실이 직접 회귀한 양**이었다. "9.1배 개선"을 헤드라인으로 썼는데 독립 증거가 아니었다.
손실과 독립인 지표는 시간축 autocorr 하나뿐이었다.
**결말**: ablation 결과 손실 없는 `conv` 가 이미 전부 달성 (JS_profile 0.00217 vs
conv_topo 0.00213, 부트스트랩 95% 구간 겹침). 애초 가설이 틀렸고 공은 아키텍처에 있었다.

## B. 적합과 적용의 자가 다름

**2026-08-13.** τ-leaping propensity 를 **연속 OM 활성합**(평균 3.69)으로 적합해 놓고
**이진 활성수**(모티브 OM 은 평균 1.30)에 적용했다. λ 가 3.53 대신 0.87 이 되어
**음이 41% 사라졌다.** 그런데 밀도비는 오히려 올라가 "성공"처럼 보였다.

**추가 사례 2026-08-13(감사 2회차).** 이 버그를 고치면서 적합을 이진으로 내렸는데,
그 선택을 정당화하는 근거는 **연속 OM 으로 잰 상관(r=+0.663)을 그대로 뒀다.**
실제로 쓰는 이진 OM 의 상관은 **Pearson +0.571 로 MODULES(+0.587)보다 낮다.**
버그 수정이 동기 근거를 무효화했는데 근거를 갱신하지 않았다.

## C. 동어반복 비교

**2026-08-13.** "낯선 모티브 D 가 모든 쌍에서 가장 멀다"고 보고했다. 모티브가
**시간의 26.7%를 직접 차지**하므로 전 영역 프로파일 JS 에는 "내가 넣은 게 거기 있다"가
섞여 있었다. 마스크 **밖**만으로 재니 A–D 가 0.087 → 0.0037 로 최소가 되어 순위가 뒤집혔다.

## D. 평균이 신호를 지움

**2026-08-13.** 모티브 통제 효과를 밀도비 **평균**으로만 봤다. 모티브별 OM 지시비가
0.58~1.61 로 갈리는데 평균은 1 근처라 "통제 실패"로 읽혔다. 상관으로 재니 r = −0.21 → +0.73.
⚠ 단 이 재정의는 **구성상 결정론**(λ = a + b·활성합)이라 확증 증거가 못 된다 — 유형 A 참조.

## E. 조용한 쓰기 손실 / 조용한 폐기

**2026-08-07.** `np.zeros_like` 는 입력의 **메모리 순서를 물려받는다**(order='K').
torch `permute` 결과를 넘기면 비연속이라 `out[i].reshape(-1)` 이 뷰가 아니라 복사본이
되고, 쓰기가 예외도 경고도 없이 사라진다. 모든 변이의 density 가 0.0 으로 보고됐다.
확인법: `np.shares_memory(out[i].reshape(-1), out)`.

**추가 사례 2026-08-13 — `generation.py` NodePool 오프바이원(선재 버그).**
`notes_label` 값은 1..23, `cycle_labeled` 노드 id 는 0..22.
`NodePool.pool` 은 **1-indexed** 로 채우는데(`pool_list.extend([notes_label[note]]*count)`)
디코더 `label_to_note_info` 는 **0-indexed** 로 푼다(`if lbl == label + 1`).
→ 풀에서 뽑힌 **23개 라벨 전부가 다른 음으로 디코딩**되고(빈도·온도 가중이 엉뚱한 음에
붙는다), 라벨 23 은 `None` 이 되어 **4.2% 의 추출이 조용히 `continue` 로 버려진다.**
`random.choice(intersect_pool)` 경로는 0-indexed 라 정상. §7.7.3 T=3.0 튜닝은 이
잘못 배선된 손잡이를 돌린 것이다.
확인법: 인덱스 규약이 둘인 코드에서 `set(pool)` 과 `set(cycle nodes)` 의 min/max 비교,
디코더가 `None` 을 돌려주는 비율 계수.

## M. 유사반복(pseudoreplication)

**2026-08-13.** OM 8개 × seed 12개 = 96 을 독립 표본으로 넣어 Welch t-test → **p = 2×10⁻⁶⁸**.
케이스 내 상관(ICC)은 지표별 0.169 / 0.740 / **0.938**, 설계효과 2.9 / 9.1 / **11.3**,
실효 표본은 96 이 아니라 **33.6 / 10.5 / 8.5**. 케이스 평균(n=8)으로 재면 p = 1.2×10⁻⁷
(여전히 유의) — **60 자릿수가 사라진다.** 음고 JS 는 p = 3×10⁻⁴ → 케이스 수준
**p = 0.10 (판별 불가)** 로 뒤집혔다.

## N. "matched / normalized" 는 이름일 뿐 보증이 아니다

**2026-08-13.** τ-leaping 에 `match_total` 을 걸어 "총 음 수를 고정 스케줄과 같게 두어
총량 오염 없는 효과만 분리"한다고 적었다. 실현 음 수는 **361.5 → 423.8 (+17.2%)** —
clip(0,n_max) 과 slot 차감이 뒤에 있어 Σλ 를 맞춰도 산출 총량은 안 맞는다.
하필 지표(onset 히스토그램 JS)가 총량에 **r = −0.869** 로 민감했다. 결과: 고정 스케줄에
**×1.2 를 곱하기만 해도**(OM 도 확률성도 없이) JS −32.1% 로 τ-leaping 의 −24.6% 를 이긴다.

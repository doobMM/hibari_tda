hibari-TDA 인터랙티브 데모

사카모토 류이치의 hibari(영화 괴물 2023 OST)를 Topological Data Analysis (Persistent Homology)로 분석하고, 곡에 숨은 cycle 구조를 시드 삼아 위상적으로 닮았지만 새로운 음악을 생성합니다. 연구 전체는 GitHub 저장소와 포트폴리오 PDF를 참조하세요.

Guided Tour — 중첩행렬로 음악을 만드는 법

음 23개 → Tonnetz 거리 → 고리(cycle) 발견 → 중첩행렬 → 직접 그려서 생성까지, 방법론을 6단계 스크롤 한 장으로 안내합니다. 필트레이션 애니메이션과 직접 칠해 듣는 미니 데모 포함. 비전공자도 5분이면 핵심을 잡습니다.

투어 시작 → Dashboard

Overlap Matrix 편집 + 생성

중첩행렬을 직접 그려 30초 음악을 즉석 생성·재생·MIDI 저장. 곡 전환(hibari·solari·aqua) 토글로 "곡의 성격이 최적 도구를 결정한다"를 대조, 라이브 모드(그리면 음악이 따라옴), 음악적 의도(음역·밀도) 슬라이더로 직관적 유도, 구조 탐험(VAE), 협화도 우선, 사진→OM, 품질 맵까지. Algorithm 1(샘플링) · 2(FC·Transformer ONNX) 모두 브라우저 내 실행.

열기 → Visualization

Tonnetz 시각화

원곡·생성본을 재생하며 Tonnetz 격자 위 H1 cycle을 동기 표시. 대시보드에서 만든 시퀀스를 그대로 받아 재생합니다. 어둠 속 새싹처럼 빛나는 그린 격자.

열기 → Visualization

Filtration 진행

거리 ε이 자라며 음들이 simplex로 연결되고 cycle이 닫히는 순간을 MIDI 동기 3D로 보여줍니다. Persistent Homology가 "오래 살아남는 고리"를 찾는 과정을 눈으로 확인.

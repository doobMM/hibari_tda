# 모티브 통제 트랙 12개의 음악적 분석 — OM이 아니라 소리로 본다

> `docs/motif_control_design.md` 가 다룬 것은 **중첩행렬(OM) 수준**의 통제 검증(모티브 보존율·자유영역
> 변주간 차이·cycle 프로파일 JS)이다. 이 문서는 그 결과물인 **실제 MIDI**를
> `pretty_midi` 로 읽어 음역·화음·리듬·모티브 간 차이를 음악 표면에서 다시 잰다.
> 분석 스크립트: `tools/analyze_motif_tracks.py` (학습·추론·PH 계산 없음 — MIDI 파싱만 하는 가벼운 스크립트).

**대상**: `output/topo_diffusion/topo_motif{A,B,C,D}_{skeleton,v1,v2}.mid` 12개
**비교 원곡**: `Ryuichi_Sakamoto_-_hibari.mid`
**기준**: 66 BPM, 8분음표 = 0.454545...초. 모든 note onset은 이 스텝 grid로 반올림해 화음/밀도를 계산한다.
**모티브 배치**(`experiments/motif_control.py`): 길이 8스텝(1마디) 모티브를 `[0,32,64,96,128,160,192,224]`
8회(32스텝마다) 삽입, T=240(109.09초) 중 시간의 26.7%.

## 1. 음역 구조 — "두 성부의 음역 분리"는 실제로 있는가

### 1.1 전제 확인 — hibari의 원본 2트랙은 음역이 아니라 시간으로 나뉜다

pretty_midi가 읽는 hibari.mid의 raw instrument는 2개다. 이것이 "두 성부"의 근거일 수 있어
먼저 확인했다.

| | inst 0 | inst 1 |
|---|---|---|
| note 수 | 2006 | 1947 |
| pitch 범위 | [52, 81] | [52, 81] |

**두 트랙의 pitch 범위가 완전히 동일하다.** 음역으로 나뉜 두 성부가 아니라, 같은 선율 소재를
시간축에서 어긋나게 배치한 두 트랙이다. inst1을 8분음표 1스텝(0.4545초) 되돌려 inst0과
얼마나 겹치는지 확인하면 **0.055**(5.5%)에 그친다 — 고정된 1스텝 캐논이 아니라, 어긋남의
정도 자체가 곡 전체에서 변한다(phase-shifting, CLAUDE.md의 "hibari 곡 고유 구조: phase
shifting" 서술과 일치). 즉 **"두 성부 음역 분리"라는 전제는 raw MIDI 트랙 구조에서는
성립하지 않는다** — 이 두 트랙은 등록(register)이 아니라 위상(phase)으로 나뉜다.

그래서 이하 분석은 "두 트랙 간 음역 분리"가 아니라 **전체 note 집합의 음고 분포가 이봉형(bimodal)인가**로
질문을 다시 세워 정량화한다.

### 1.2 표 1 — 음역 구조

Sarle's bimodality coefficient(BC, population 정의: `(skew²+1)/(kurtosis+3)`)를 쓴다.
균등분포 기준값은 5/9 ≈ **0.556**이며, 이보다 크면 이봉/다봉 형태로 본다.
`gap`은 IQR(25~75%) 내부에서 가장 큰 반음 간격, `valley`는 그 중점, `mass<`/`mass>`는
그 지점 기준 note 질량 비율이다.

**BC는 13개 트랙 전부 0.44~0.51로 이봉분포 기준값(0.556)에 못 미친다.** hibari 원곡부터
이봉형이 아니다. 12개 생성 트랙도 마찬가지다 — "생성 트랙에 원곡의 이봉 구조가 있는가"라는
질문은 **원곡 자체에 그 구조가 없으므로 답할 대상이 없다.**

`gap`이 13개 중 12개에서 **정확히 pitch 61 부근**(valley=61.0)에 뚜렷하게 잡힌 것은 그 대신
다른 사실을 보여준다. hibari가 쓰는 pitch class는 `{0,2,4,5,7,9,11}`(C major/A minor 온음계,
CLAUDE.md의 "hibari 7 diatonic"과 일치)이고 **pitch class 1(C#/Db)은 전체 494초 동안 단 한
번도 등장하지 않는다.** 61은 pitch class 1의 한 옥타브일 뿐이다. 즉 이 gap은 두 성부의
음역 경계가 아니라 **온음계 어휘에서 항상 비어 있는 반음 하나**이며, 생성 트랙이 같은
note 풀에서 뽑으므로 같은 자리에 같은 gap이 그대로 복제된다(A_v1, D_v1의 대조군 확인
결과 pitch class 어휘가 hibari와 동일 `{0,2,4,5,7,9,11}`). B_v1만 valley가 58로 갈라진 것은
표본이 작을 때(373 note) IQR 경계가 살짝 밀린 우연이다.

**hibari 대 생성 pooled pitch 분포 JS divergence = 0.02785**(`eval_metrics.py`와 동일한
자연로그·eps=1e-10 정의). 음고 분포의 전체 모양은 닮았지만 완전히 같지는 않다 — §1.2 표의
median이 hibari 67 대비 생성 트랙 대부분 62~65로, **약 2~5반음 아래로 쏠려** 있다.

**결론**: 두 성부 음역 분리라는 형태의 이봉분포는 원곡에도, 생성 트랙에도 없다.
있는 것은 (1) 12트랙 모두가 물려받은 온음계 어휘의 고정된 빈 반음 하나, (2) 생성 트랙의
중앙값이 원곡보다 살짝 낮게 쏠리는 경향이다.

## 3. 리듬/밀도 — 모티브 32스텝 주기가 표면에 보이는가

### 3.1 자기상관 + 창 안/밖 밀도

`ac(lag32)`는 onset 개수 시계열의 lag=32 자기상관, `rank32`는 lag 1~80(=최대 80스텝) 중
lag32의 내림차순 순위(1이 최댓값), `in_window`/`out_window`는 모티브 배치 구간(8×8=64스텝,
26.7%) 안/밖 각각의 스텝당 평균 onset 수, `ratio`는 그 비.

**세 가지가 동시에 참이다.**

1. **자기상관은 뚜렷하다.** ac(lag32)는 0.25~0.55, 80개 후보 lag 중 순위 1~3위(평균 1.5~2위) —
   우연 수준(순위 40 근방)과는 거리가 멀다. 12트랙 중 5개(A_v1, C_skeleton, C_v2, D_skeleton,
   D_v2)는 lag32 **자체가** 전체 자기상관의 최댓값이고, D_v1은 lag64(=32의 배수)가
   최댓값이다. **모티브가 32스텝마다 심겼다는 사실은 onset 시계열의 주기성으로 실제 남는다.**
2. **하지만 밀도의 on/off 대비는 약하다.** in/out 비율은 0.93~1.38, 역할 평균은 1.10~1.18 —
   모티브 창 안이 바깥보다 많아야 10~18% 많을 뿐이다. C 계열(0.930~0.953)은 오히려 창
   **밖**이 더 밀도가 높다. `output/topo_diffusion/README.md`가 말하는 "자유영역을 0으로
   비운 뼈대"는 **OM(중첩행렬) 수준**의 이야기이지, 뼈대 MIDI에서 자유영역이 무음이 된다는
   뜻이 아니다 — 실측하면 skeleton 트랙도 창 밖에서 스텝당 평균 1.3개 안팎의 note가 계속
   난다.
3. **이유는 코드에 있다.** `generation.py`의 `algorithm1_optimized`는 각 스텝에서 뽑을 note
   개수(`inst_len[j]`)를 OM과 무관하게 미리 정해진 고정 스케줄(`MODULES`,
   `experiments/run_dft_gap0_suite.py:63` 등에 정의된 3/4 반복 패턴)에서 가져온다. OM이
   결정하는 것은 "몇 개를 뽑을까"가 아니라 "어떤 note 풀에서 뽑을까"뿐이다 — cycle이
   활성화된 스텝(`flag != 0`)은 교집합 note 풀에서, 비활성 스텝(`flag == 0`, 자유영역)은
   `_sample_avoiding_neighbors`로 이웃을 피해 여전히 note를 뽑는다
   (`generation.py:271-326`). 즉 **모티브는 "어떤 음이 나오는가"는 조건화하지만
   "언제 소리가 나는가"는 거의 조건화하지 않는다.** 이는 `motif_control_design.md` §7
   항목 5("통제의 대상은 OM이지 음표가 아니다")가 이미 짚은 한계이며, 이번 실측이 그
   한계를 음악 표면의 숫자로 확인해 준 것이다.

**B–D가 pitch·interval-class 두 지표 모두에서 가장 멀다.** 이는 OM 수준
(`motif_control_design.md` §6.3, cycle 활성 프로파일 JS)에서도 B–D=0.15274로 전체 6쌍 중
최댓값이었던 것과 **일치한다** — 위상 수준의 차이가 음악 표면(pitch, interval)까지
관통해 재현된다는 독립적 확인이다.

다만 정도는 다르다. 각 모티브의 "나머지 셋과의 평균 거리"(pitch JS 기준):

| 모티브 | 평균 거리 |
|---|---|
| A | 0.00753 |
| **B** | **0.01200** |
| C | 0.00987 |
| **D** | **0.01228** |

OM 수준에서는 D가 A/B/C 군집에서 뚜렷이 떨어져 나왔지만, 음악 표면의 pitch 분포로는
**D(0.01228)와 B(0.01200)의 차이가 거의 없다** — D가 "가장 이질적"이라는 서술은 pitch
분포만 보면 근소한 우위이지 압도적이지 않다. OM에서 뚜렷했던 분리가 Algorithm 1의
확률적 샘플링을 거치며 다소 완화된다.

### 4.2 화음 밀도로 본 D

| 모티브 | mean_chord_size (3역할 평균) | 역할별 |
|---|---|---|
| A | 1.969 | 1.870 / 1.989 / 2.047 |
| B | 2.057 | 1.901 / 2.119 / 2.152 |
| **C** | **2.110** | 1.888 / 2.233 / 2.207 |
| **D** | **1.905** | 1.775 / 1.884 / 2.054 |

D는 네 모티브 중 화음이 가장 성기다(1.905, 최저). 특히 `D_skeleton`(1.775)은 12트랙
전체를 통틀어 가장 성긴 화음이다. `motif_control_design.md`가 D를 "hibari가 거의 쓰지
않는 cycle 조합(6, 7, 9)으로 만든 합성 모티브"라고 설명한 것과 방향이 맞다 — 원곡이
잘 쓰지 않는 cycle 조합은 note 풀에서의 교집합도 좁아, 결과적으로 화음이 성겨질 여지가
있다. 다만 표본이 4개 모티브뿐이라 통계적으로 확정할 수는 없다.

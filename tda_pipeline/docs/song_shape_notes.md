## 1. 무엇을 본질로 잡았나 — 되풀이의 꼴(형식)

곡 = 시간 순서의 한 가닥. 두 시각의 **맥락**(그 앞뒤 4박에 울리는 음)이 닮았으면 그 두 시각을 가까이 놓는다.
되풀이가 많은 곡은 작게 말리고, 나아가기만 하는 곡은 길게 풀린다. 단백질이 아미노산 사슬을 접촉으로 접는 것과 같은 꼴이다
(곡의 자기유사성 행렬 = 접촉 지도).

- **색** = 그 대목 음이름들의 5도권 방향(레 쪽이 금빛), 밝기 = 음역. **굵기** = 그 자리를 지나간 횟수(stock). **가닥** = 시간의 흐름(flow).
- 모형과 매개변수는 `song_fold.py` 머리말과 `DEF`. 길이 단위는 8분음표 = 1, 노드 하나 = 0.5박.
- 기존 가중치 그래프(intra + rate × inter)와의 관계: 그 그래프는 **맥락 길이 1스텝**으로 같은 화음을 한 점에 모은 것이다.
  맥락을 4박으로 늘리면 그물이 풀려 형식이 드러난다. 같은 가족의 양 끝이다(아직 식으로 보이지는 않았다 — 관찰).
- ⚠ 여기의 점은 **음이 아니라 시각**이고, 구멍은 "되돌아옴" 이다. 정본 PH 의 음 고리(H₁)와는 다른 대상이다. 둘의 관계는 재지 않았다.

참고 프로젝트를 어떻게 썼나
| 프로젝트 | 쓴 것 |
|---|---|
| differential-line | 가닥을 이웃끼리 당기고 남남끼리 미는 힘으로 푼다. 여기에 **닮은 시각끼리 당김**을 더했다 |
| particle-life | 끌림 행렬로 모양이 떠오른다는 형식. 행렬 = 곡의 자기유사성(시각 × 시각). ※ 글자 그대로(종 = 음, 행렬 = 흐름)는 해 봤고 버렸다 — §4 |
| OrigamiSimulator | 편 상태 ↔ 접은 상태를 한 막대로 오간다(펴면 두루마리). 모든 접힘을 동시에 푼다 |
| Matrix-3D | 한 입력 → 돌려 볼 수 있는 3차원. 끌어 돌리기·당기기 |
| WebGL-Fluid | 쓰지 않았다(붓질 느낌의 음영만) |
| MarkovJunior | 모양에는 쓰지 않았다. "다른 길로"(닮은 자리에서 건너뛰며 새 순서로 연주)가 같은 생각이다 — 출력의 모든 국소 창이 원곡에 있다 |

## 2. 페이지

- 끌기 = 돌리기 · 휠/두 손가락 = 당기기 · **몸을 누르기 = 그 대목부터 듣기** · Space · ←→ 곡 · W 다른 길로 · F 펴기/접기. 글자 키는 `ev.code`.
- 자동 재생 없음. `?silent` 무음. `?song=<slug>` · `?sigma=<굵기>`. 밝은 바탕. 지금 울리는 음 이름(계이름+옥타브)이 오른쪽 위에 뜬다.
- 검증용 문 `window.__shape`.

## 3. 발견 (탐색적 — 매개변수를 눈으로 고른 뒤 본 것)

- **hibari 와 Piano Phase 는 같은 과정이다.** hibari 의 두 성부는 같은 모듈을 주기 32 와 33 으로 돈다. 둘 다 0에서 같이 시작해
  1056스텝(= 32 × 33) 뒤 다시 만난다 — 곡은 한 바퀴의 위상 순환 전체다(이 MIDI 기준. 정본 파이프라인은 둘째 악기를 33스텝 뒤로 놓고 다룬다).
- **성부를 합쳐 들리는 대로 보면 hibari 는 앞뒤가 대칭이다**: 모듈 a 와 모듈 33−a 가 같다(가장 닮은 먼 시각의 지연 = 1056 − 65a).
  두 손이 같은 무늬를 돌 때 "누가 쳤는지" 를 가리지 않으면 상태는 원 위의 **순서 없는** 두 점이고, 그 공간은 뫼비우스 띠다(경계 = 같이 칠 때).
  성부를 가리면 이 짝이 사라지고 대신 지연 528(오른손 반 모듈)이 짝이 된다. → §5 P5
- 곡마다 "다시 나오는 대목의 비율"(rec80: 가장 닮은 다른 시각과의 닮음 ≥ 0.8 인 시각의 비율)이 크게 다르다: hibari·Piano Phase 1.00 … Bach 0.14 · A Flower 0.06.
- 굵기를 올려도 남는 구멍은 13곡 중 Piano Phase 하나뿐이다(`song_shape_mesh.json`) — 위상 상태들을 도는 목걸이.

## 4. 해 보고 버린 것

- **particle-life 그대로** (종 = 음, 끌림 = 음 사이 흐름 intra + inter, 입자 1100개): 6곡 모두 공 안에 작은 뭉치가 흩어진 같은 그림 — 곡이 구별되지 않는다.
- **음의 그물** (음 = 자리(흐름 거리의 3차원 MDS), 변 = 흐름): 음이 50개를 넘는 곡은 전부 털뭉치. hibari(17음)·Piano Phase(7음)만 읽힌다.
- 닮음에 문턱을 두고 똑같은 대목만 붙이기: hibari 가 공 하나로 뭉친다(반 모듈 차이가 전부 "반쯤 닮음" 이라). → 닮은 만큼 가깝게(거리 = ρ·(1 − 닮음)).

## 5. 검사 결과

예측은 `run_song_shape_checks.py` 머리말에 실행 **전에** 적었다. 원본 `docs/step3_data/song_shape_checks.json` (1122초).
시드 = 초기 자리에 잡음(σ 0.5)을 얹은 것. "거리 상관" = 같은 노드 300개의 쌍 거리끼리의 Pearson r (회전·이동 불변).

| | 예측 | 결과 | 판정 |
|---|---|---|---|
| P1a 안정성 | 되풀이 많은 6곡의 시드 간 거리 상관 중앙값 ≥ 0.7 | 최소 0.806 (hibari 1.000 · reich 0.981 · mcml 0.950 · ravel 0.842 · solari 0.830 · aqua 0.806) | ✓ |
| P1b | 13곡에서 rec80 과 Spearman ≥ 0.5 | 0.577. 13곡 전체 범위 0.752(debussy) ~ 1.000 | ✓ |
| P2 구별 | (곡, 시드) 1-최근접 분류 ≥ 0.85 | 0.973 (75개 중 73) | ✓ |
| P3 시각 뒤섞기 | 13곡 모두 rec80 ≤ 0.10, 원래 배치와 r ≤ 0.2 | rec80 최대 **0.225**(The Last Emperor, 나머지 12곡 ≤ 0.10) · r 최대 **0.216**(solari, 나머지 ≤ 0.142) | ✗ (한 곡씩 넘음) |

| P5 hibari 자리바꿈 짝 | 합치면 스텝의 ≥ 90% 에서 **가장 닮은** 먼 시각이 지연 1056 − 65a · 가리면 ≥ 90% 가 지연 528 | 합침 **0.71** · 가림 **0.39** | ✗ |

읽는 법
- **남는 것**: 같은 곡은 다시 접어도 같은 꼴이고(P1), 곡끼리는 구별되며(P2), 매개변수를 ±30% 흔들어도 되풀이 많은 곡의 꼴은 남는다(P4).
  시각을 뒤섞으면 되풀이가 거의 사라진다(12/13 곡) — 모양은 음 재료가 아니라 **순서**에서 나온다.
- **빗나간 것**: P3 는 문턱을 한 곡씩 넘었다. P3b 는 "도막을 섞어도 재료는 같으니 되풀이는 남는다" 는 내 예측이 틀렸다 —
  맥락 창(4박)이 도막 경계를 걸치므로 도막을 섞으면 맥락 자체가 바뀐다. 대조군 설계가 나빴다(도막을 창보다 훨씬 길게 잡았어야 한다).
- **P5**: 기준을 "가장 닮은 시각이 그 짝" 으로 잡았는데, 똑같이 닮은 짝이 여럿이면(자리바꿈 짝과 528 짝이 둘 다 있다) argmax 는 그중 하나만 고른다.
  모듈별 **중앙 지연**은 15개 모듈 전부 공식과 일치한다(991, 926, …, 81). 사후에 예측한 짝 자리의 닮음을 직접 재면(`posthoc_P5_direct`, 탐색):
  합친 맥락에서 자리바꿈 짝이 닮음 ≥ 0.95 인 스텝 **78.7%**(중앙 1.00, 5스텝 어긋난 대조 자리 0%), 성부를 가리면 그 짝은 **0%**(중앙 −0.18).
  → "합치면 앞뒤가 대칭" 은 스텝의 약 8할에서 성립한다(나머지는 왼손의 쉼 한 칸 때문에 어긋나는 것으로 보인다 — 확인하지 않았다). 사전 기준은 통과하지 못했다.

그물(`tools/verify_shape_songs.mjs` → `song_shape_mesh.json`): 13곡 모두 닫힌 면(열린 변 0). 손잡이 수는 굵기 σ 0.5 에서 0(hibari) ~ 194.5(bach)
— 실타래의 가닥 사이 틈이 세어진 것이라 "되돌아옴" 과 1:1 이 아니다. σ 0.8 이상에서는 Piano Phase 만 1 이 남는다.
메셔(`tools/verify_shape_core.mjs`): 답이 알려진 모양(공·고리·두 공·8자) 13/13 통과.

## 6. 한계와 다음

- 매개변수(ρ·문턱·밀기 반지름·번짐·벽)는 미리보기를 눈으로 보고 골랐다. 다른 값이면 다른 몸이 나온다(§5 P4 가 그 크기).
- 되풀이가 적은 곡은 모두 "색이 다른 실타래" 다 — 형태보다 색과 덩어리로 구별된다. 조옮김된 되풀이(푸가 주제의 다른 조 진입)는 닮음으로 치지 않는다.
- 사람이 그 모양에서 곡을 알아보는지는 재지 않았다.
- 다음 후보: ① 조옮김을 닮음으로 치기(나란히, 다른 빛으로) ② "다른 길로" 로 만든 새 곡을 다시 접어 새 몸 보기(생성 ↔ 모양) ③ rate 에 해당하는 손잡이(성부를 가리는 정도) ④ 실기기 확인.

## 2. Lenia 한 쪽 요약

Bert Chan (2019), *Lenia — Biology of Artificial Life*, Complex Systems. arXiv:1812.05433. 코드 MIT.
Conway 의 생명 게임을 **공간·시간·상태 모두 연속**으로 일반화한 세포 자동자.

```
갱신    A(t+Δt) = [ A(t) + Δt · G( K ∗ A(t) ) ]₀¹          Δt = 1/T,  [·]₀¹ = 0~1 로 자르기
커널    K_C(r) = exp(α − α/(4r(1−r))),  α=4                 ← r=0·r=1 에서 0, r=½ 에서 최대 = 고리형
퍼텐셜  U = K ∗ A                                           ← 정규화된 이웃 가중합
성장    지수형  G(u) = 2·exp(−(u−μ)²/(2σ²)) − 1
        사각형  G(u) = 2·𝟏[μ±σ](u) − 1                     ← 창 안이면 +1, 밖이면 −1
```

- **생명 게임은 Lenia 의 특수한 경우**다: R=T=P=1, 사각 커널, μ=0.35, σ=0.07.
- 성장 함수 하나 안에 **되먹임 한 쌍**이 있다 — 알맞으면 자라고(강화), 고립·과밀이면 줄어든다(균형).
- 격자가 아닌 변형: **Particle Lenia**(Mordvintsev·Niklasson·Randazzo 2022),
  **Flow-Lenia**(Plantec 외, *Artificial Life* 2025, 질량 보존).

## 3. [측정] 무엇이 연결되고 무엇이 아닌가

직관을 네 개의 예측으로 바꿔 **실행 전에 적고** 쟀다. 둘은 통과, 둘은 기각.

### 연결 ① — echo.html 은 이미 "고리 위의 이산 Lenia" 다 (코드 대응)

| echo.html 의 현재 규칙 | Lenia 용어 | 차이 |
|---|---|---|
| `sounding(t)` — 울리는 음의 **이진** 집합 | 상태 | 연속이 아니다 |
| `act[c] = Σ_{n∈c,울림} rar(n) / Σ_{n∈c} rar(n)` | 퍼텐셜 U = K∗A | **같다.** K = 희귀도 가중 고리 소속 |
| `act ≥ 0.35` → 켜짐 | 성장 G | 계단. 생명 게임 극한과 같은 모양 |
| 생성음 잔향의 세대 감쇠 | G 의 음수 영역 | 세대 수에만 의존. **밀도에 의존하지 않는다** |

### 기각 — "H₁ 고리 = Lenia 의 고리형 커널" (P1)

**예측**: H₁ 고리는 "변은 있고 삼각형은 없는" 구간에 산다 → 공동소속은 **중간 거리에서 최대**.
**결과**: 반대. **가장 가까운 쌍이 가장 많이 공유하는 덩어리형**.

| 거리 (5분위, 가까움 → 멂) | Q1 | Q2 | Q3 | Q4 | Q5 | 순위상관 ρ | 무작위 대조군 |
|---|---|---|---|---|---|---|---|
| DFT 음악거리 | **1.31** | 1.05 | 0.29 | 0.13 | 0.00 | **−0.615** | 0.000 ± 0.071 |
| hybrid rate=0.0 | **1.73** | 0.62 | 0.22 | 0.02 | 0.02 | −0.652 | 0.001 ± 0.073 |
| hybrid rate=1.0 | **1.61** | 0.69 | 0.08 | 0.18 | 0.00 | −0.629 | 0.001 ± 0.070 |

- **구조는 강하다** (p = 0.0005, 2000회 순열의 하한). **모양이 Lenia 와 반대일 뿐이다.**
- 고리의 "구멍"은 **조합적**(어느 삼각형이 비었나)이지 **거리상**이 아니었다.
- → 커널은 데이터에서 나온 것(덩어리형 고리 소속)을 쓰고, **고리형 커널을 넣지 않는다.**
  기어다니는 생명체 대신 **입자의 움직임**으로 모션을 얻는다(결정 2).

### 연결 ② — 정본 중첩행렬에는 이미 되먹임 한 쌍이 들어 있다 (P4)

`overlap.py:build_overlap_matrix` 의 **`threshold=0.35` 는 활성도 임계가 아니라 "고리가 켜질 수 있는
시간 비율의 상한"** 이다(하한 0.25). 상한을 맞추려고 **짧게 켜진 구간을 잘라낸다**(`scale`).

그런데 헤드라인 JS=0.00902 를 만든 건 이 구성이 아니다. **정본 중첩행렬은 둘**이다.

| | ① 이진 scale OM (§3 원 구성) | ② **헤드라인 OM** (§7.7, JS=0.00902) | echo.html 규칙 |
|---|---|---|---|
| 정의 | 이진 활성 → 최소 지속 필터 → 시간 비율 상한 | **연속 활성도 ≥ τ_c** (고리별) | 연속 활성도 ≥ 0.35 (평탄) |
| τ | 0.35 = 시간 비율 상한 | `tau_profile` 0.1~0.7 ¹ | 0.35 (①의 숫자를 다른 뜻으로 빌림) |
| 지속 (깜빡임 제거) | **있다** — 최소 4~170 스텝 | 없다 | 없다 |
| 밀도 상한 | **있다** — 켜진 시간 ≤ 0.35 | 없다 — 최대 0.821 | 없다 — 최대 0.563 |
| 행당 켜진 고리 · 빈 행 | 4.38 · 161/1088 | 4.83 · **0/1088** ² | — |
| ①과의 일치율 | — | 61.4% | 64.7% |

¹ `percycle_tau_dft_gap0_alpha_grid_results.json` α=0.25 `tau_profile` = `[0.7, 0.7, 0.3, 0.7, 0.7, 0.4, 0.1, 0.3, 0.4, 0.1, 0.5, 0.35, 0.4, 0.3]`, js_mean 0.009022 — **헤드라인 그 자체**.
² CLAUDE.md 에 기록된 정본("zero-row 0/1088")과 일치 — τ_c 를 올바로 읽었다는 교차 검증.

**요점**: ②(헤드라인)는 **순간적**이라 관성이 없고, ①은 관성과 밀도 상한이 있다. Lenia 규칙은
**②에서 출발해 ①이 가진 성질을 실시간으로 더하는 것**으로 정의할 수 있다 (§4-1).

### 연결 ③ — 음들은 2D 화면에 충실하게 펼쳐진다 (P2)

| 거리 | stress-1 (1D / **2D** / 3D) | 2D 고유값 몫 | 고리 이웃 보존 (2D) | 무작위 좌표 |
|---|---|---|---|---|
| DFT 음악거리 | 0.392 / **0.064** / 0.097 | **94.3%** | 34.9% | 13.5% |
| hybrid rate=1.0 | 0.370 / 0.134 / 0.161 | 92.5% | 41.3% | 13.4% |

stress 0.064 는 Kruskal 기준 **"좋음"**. **화면 위치 = 화성 거리** 라고 말할 수 있다.
고리 이웃은 부분적으로만 모인다(35%) — 고리는 화면에서 **여러 곳에 걸친 별자리**로 보일 것이다.
**그래서 입자가 필요하다**: 고리가 켜지면 흩어진 구성원이 모여 별자리가 조여진다(§4-3).

### 연결 ④ — 곡의 주기가 보인다, 단 가장 강한 건 16 (P3)

| lag (스텝) | 8 | **16** | 17 | 24 | 31 | **32** | **33** | 34 | 48 | 64 |
|---|---|---|---|---|---|---|---|---|---|---|
| 자기상관 | −0.28 | **+0.80** | +0.60 | −0.30 | +0.36 | **+0.71** | **+0.70** | +0.35 | +0.59 | +0.52 |
| 시간 셔플 대조 (95%) | | +0.03 | | | | +0.03 | +0.03 | | | |

- 주기성은 강하다. 원곡을 그리면 **4초(16스텝) 호흡**이 보일 것이다.
- **예측은 틀렸다** — 최강은 32 가 아니라 16. 모듈이 거의 같은 16스텝 두 개로 되어 있다.
- 봉우리가 16→17, 32→33 으로 **넓게 퍼져** 두 손 32·33 혼합과 맞지만, **악기를 합친 행렬이라 확증 불가**.
- ⚠ 대조군 하나(열별 원형 이동)는 이 통계에 불변이라 **무효**였다. 판정에 쓰지 않았다.

### ⚠ 0.35 가 세 번 나온다 — 해석하지 말 것

`build_overlap_matrix` 의 시간 비율 상한 · echo.html 의 활성도 임계(빌려 옴) · Lenia 생명 게임 극한의 μ.
서로 다른 양이다. 지난 세션의 `주기 = 30 + 고리번호` 와 같은 함정이다.

### 4-1. [규칙] 갱신 규칙 — 확정

**원칙: 헤드라인 OM 에서 출발한다. 새 매개변수는 하나도 탐색하지 않는다 — 전부 데이터에서 고정한다.**

```
상태     A_c(t) ∈ [0,1]     고리 14개의 활성도
입력     S_n(t) ∈ {0,1}     음 23개가 지금 울리는가 (1a: 원곡 / 2: 탭 + Algorithm 1)
퍼텐셜   U_c = Σ_{n∈c} rar(n)·S_n / Σ_{n∈c} rar(n)                  ← overlap.py 연속 활성도 그대로
성장     G_c(u) = +1  if  τ_c ≤ u ≤ u_max
                  −1  otherwise                                     ← Lenia 사각형 성장 (창의 하한 = 정본 τ_c)
갱신     A_c ← clip( A_c + G_c(U_c) / T, 0, 1 )                     ← Lenia 갱신식
읽기     OM_c = [ A_c ≥ ½ ]  →  Algorithm 1 (변경 없음)
```

| 매개변수 | 값 | 출처 | 하는 일 |
|---|---|---|---|
| τ_c | `tau_profile` (0.1~0.7) | 헤드라인 JS=0.00902 의 그 값 | 창의 하한 |
| **T** | **25 스텝 = 6.25초** | 정본 이진 scale OM 의 고리별 최소 지속 길이, **전반부**(0~543) 중앙값 12.5 × 2 (전곡도 같다) | 관성. 지지가 약 12.5 스텝 이어져야 켜지고, 끊겨도 약 12.5 스텝 머문다 |
| u_max | **1a·1b: 1 (끔)** · **2: 0.688** | 원곡 양의 활성도 95% 분위 (전반부 = 전곡 = 0.688) | 과밀. "hibari 가 평소 가지 않을 만큼 꽉 차면 줄어든다" |

**정확한 특수 경우 — 메커니즘 뺀 대조군이 근사가 아니라 정확하다**:
**T = 1 이고 u_max = 1 이면 OM_c = [U_c ≥ τ_c] — 헤드라인 OM 과 정확히 같다.**
(G=+1 이면 A 가 한 스텝에 1 로, −1 이면 0 으로 간다. 정본 비교도 `>=` 다 — `build_percycle_overlap`.)
그러므로 Lenia 가 바꾸는 것은 **관성(T>1)과 과밀(u_max<1) 두 가지뿐**이고, 각각 따로 켜고 끌 수 있다.

**Lenia 가 더하는 것**:

| | 효과 | 정본 ①(이진 scale OM)의 대응 |
|---|---|---|
| 관성 T=25 | 12.5 스텝 미만의 지지로는 켜지지 않는다 → 깜빡임 제거. 꺼질 때도 12.5 스텝 **여운** | 최소 지속 필터 `scale` — **비슷하지만 같지 않다** (정본은 구간 경계를 옮기지 않는다) |
| 과밀 u_max=0.688 | 고리가 지나치게 꽉 차면 줄어든다 | 시간 비율 상한 — **메커니즘이 다르다** (정본은 짧은 구간을 잘라 상한을 맞춘다) |

⚠ 지수형 G(종 모양)는 쓰지 않는다. 사각형이어야 T=1 에서 정본과 **정확히** 같아진다.
부드러운 G 는 이 규칙이 검증된 뒤의 선택지다.

### 4-2. 단계 1a — 원곡을 받는 Lenia 화면 (고정 지도)

```
지도     23개 음 → DFT-MDS 좌표 (고정)
입력     원곡 events → S_n(t)  →  §4-1 규칙 (T=25, u_max=1)  →  A_c(t)
층 ①     음 n 이 울림                → 그 자리의 작은 빛
층 ②     고리 c 의 A_c               → 순회 순서대로 이은 **닫힌 곡선** (= H₁ 대표 고리)의 밝기
층 ③     G_c 의 부호                 → 자라는 중 = 따뜻한 색, 줄어드는 중 = 차가운 색
소리     원곡 MIDI → audio-playback.js
```

- **화면이 곧 상태다.** 독립된 장식 시뮬레이션을 돌리지 않는다. 모든 픽셀은 (S, U, A, G) 의 함수다.
- 기대되는 모습: 4초 호흡(16), 8초 파도(32·33), **4분 24초마다 다시 맞는** 느린 흐름(1056).
  고리가 켜질 때 따뜻해지고, 꺼진 뒤 6초쯤 식으며 사라진다(관성의 여운).

### 4-3. 단계 2 — 생성 과정, 제자리에 묶인 입자

**새 페이지**로 만든다. **`echo.html` 은 한 글자도 고치지 않는다 — 대조군이다.**

```
탭 (화면 위치)   → 가장 가까운 음 n 이 울림       ← 화면이 화성 지도라 "어디를 누르나" 가 뜻을 갖는다
S → U → G → A → OM → Algorithm 1 → 새 음 → S    ← echo.html 의 되먹임 회로 그대로, 규칙만 §4-1 (u_max=0.688)
```

**입자의 힘** — Particle Lenia 에서 **영감**을 받았을 뿐 그 에너지 정식화(E = R − G)는 아니다.
이름을 그렇게 부르지 않는다.

```
x_i, v_i     음 i 의 위치·속도.  x_i⁰ = DFT-MDS 좌표 (집)
F_i = − k_home · (x_i − x_i⁰)                                          ← 집으로 돌아가는 스프링 (지도를 지킨다)
      + k_bind · Σ_c A_c · 𝟏[i∈c] · (x̄_c − x_i)                        ← 켜진 고리의 무게중심 쪽으로
      − k_rep  · Σ_{j≠i, |x_j−x_i|<r₀} (x_j − x_i) / |x_j − x_i|³       ← 겹침 방지
v_i ← γ·v_i + F_i·dt,   x_i ← x_i + v_i·dt                             (γ < 1, 감쇠)
```

- **고리가 켜지면 흩어진 구성원이 모여 별자리가 조여지고, 꺼지면 집으로 풀린다.**
  위치가 곧 상태다 — 움직임을 따로 지어내지 않는다.
- 닫힌 곡선(H₁ 고리)은 입자를 따라 그린다. 켜진 고리는 조여진 밝은 고리로 보인다.
- k_home·k_bind·k_rep·γ 는 **보기 좋게 조율하는 표시 매개변수**다. 소리에 영향이 없으므로 조율해도 된다.
  단 **입자가 집에서 화면 폭의 15% 넘게 벗어나지 않게** 잡는다
  (지도가 무너지면 "위치 = 화성 거리" 가 깨진다).
- echo.html 에서 그대로 가져올 것: `add()` 로 끊지 않는 소리, 즉발음 전용 플레이어, 두 손 32·33,
  첫 조작까지 20자 이하, **손잡이 없음**.

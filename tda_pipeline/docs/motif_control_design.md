# 중심 모티브로 음악을 통제한다 — RePaint 조건부 중첩행렬 생성 (2026-08)

> `docs/topo_diffusion_report.md` 에서 학습한 위상 손실 디노이저를, **재학습 없이** 악기로 바꾼 기록.
> 구현: `experiments/motif_control.py`

---

## 1. 문제 — 무조건부 생성은 통제가 아니다

`run_topo_diffusion.py` 가 학습한 것은 hibari 중첩행렬(OM)의 **분포**다.
거기서 샘플을 뽑으면 "hibari 같은 들판"이 나오지만, 어떤 들판이 나올지는 시드가 정한다.
사용자가 원한 것은 그게 아니었다.

> "hibari 로부터 출발해서, **중심 모티브를 중첩행렬을 이용해 제공하면**
>  출력되는 음악을 **통제**하는 경우"

| | 무조건부 샘플링 | 조건부 샘플링 (본 문서) |
|---|---|---|
| 입력 | 시드 하나 | 시드 + **모티브 패치 + 마스크** |
| 사용자가 정하는 것 | 없음 (뽑기) | 무엇이 / 어디에 / 얼마나 |
| 같은 조건 반복 시 | 매번 무관한 결과 | **모티브는 같고 사이만 다르다** |
| 검증 질문 | "hibari 같은가" | "준 것이 살아남았는가 + 안 준 곳은 자유로운가" |

두 번째 열의 마지막 줄이 핵심이다. 통제가 됐다는 것은 **결과가 하나로 고정됐다는 뜻이 아니라**,
고정한 곳은 고정되고 나머지는 여전히 다양하다는 뜻이다. 통제와 복제는 다르다.

## 2. RePaint — 왜 재학습이 필요 없는가

디퓨전 역과정은 매 스텝에서 "현재 상태 x_i 를 조금 덜 노이즈인 x_{i-1} 로 옮기는" 국소 연산이다.
이 연산은 **어떤 조건도 모른 채** 학습됐지만, 조건은 학습이 아니라 **덮어쓰기**로 넣을 수 있다.

$$x_{i-1} \;=\; m \odot \big(\sqrt{\bar\alpha_{i-1}}\,x^{\text{motif}} + \sqrt{1-\bar\alpha_{i-1}}\,\epsilon\big)
\;+\;(1-m)\odot p_\theta(x_{i-1}\mid x_i)$$

- $m \in \{0,1\}^{T\times K}$ — 1인 셀은 **사용자가 준 값 그대로**, 0인 셀만 모델이 채운다.
- 아는 영역을 그냥 원본으로 박아 넣지 않고 **그 시점의 노이즈 수준으로 흐려서** 넣는다.
  x_i 전체가 노이즈 수준 i 에 있어야 디노이저가 학습 때 본 것과 같은 입력을 받기 때문이다.
- $\theta$ 는 건드리지 않는다. 조건은 **샘플링 루프 안에만** 있다.

이것이 RePaint(CVPR 2022)의 inpainting 이며, 우리 문제에서는
"OM 의 일부 마디를 사용자가 채워 놓고 나머지를 모델이 잇게 하는" 작업이 된다.

### 2.1 되돌림 재샘플링 (jump)

덮어쓰기만 하면 마스크 경계에서 어색해진다. 모델이 채운 자유영역은 자기가 방금 만든 문맥만 보고
정해졌을 뿐, **그 옆에 강제로 들어온 모티브를 본 적이 없기** 때문이다.

RePaint 의 해법은 같은 노이즈 수준에서 앞뒤로 왕복하는 것이다.

$$x_i \;\leftarrow\; \sqrt{\alpha_i}\,x_{i-1} + \sqrt{\beta_i}\,\epsilon
\qquad(\text{한 스텝 되돌린 뒤 다시 디노이즈})$$

되돌릴 때마다 자유영역이 **이미 확정된 모티브를 문맥으로 다시 본다**. 구현에서는
`JUMP_U = 4` 회, 전체 디퓨전 스텝의 **마지막 35% 구간에서만**(`JUMP_FROM = 0.35`) 적용한다 —
고노이즈 구간에서는 아직 경계랄 것이 없어 비용만 들기 때문이다.

### 2.2 임의 길이 — MultiDiffusion 융합

모델은 T=60 창 하나로 학습됐지만 곡은 T=240(약 1분 50초)이다.
`_fused_eps()` 가 stride 15 로 겹치는 창들의 ε 예측을 **Hann 창 가중 평균**해 하나로 합친다.
겹치는 창들을 한 배치로 묶어 한 번에 통과시키므로 CPU 에서도 감당된다.
RePaint 덮어쓰기는 이 융합된 ε 위에서 이뤄진다 — 즉 **조건부성과 장형 합성이 같은 루프 안에** 있다.

## 3. "중심 모티브"의 조작적 정의

모티브를 사람이 고르면 결과가 취향에 의존한다. 그래서 곡에서 **세어서** 뽑는다.

> **중심 모티브** = 길이 L 창 중, 곡의 다른 위치에서 **같은 cycle 활성 패턴이 가장 많이 재현되는** 것.

구현 (`extract_central_motifs`):

| 단계 | 규칙 |
|---|---|
| 창 길이 | `MOTIF_LEN = 8` 스텝 = 1 마디 (§2 정의) |
| 재현 판정 | 다른 창과의 **셀 일치율 ≥ 0.90** |
| 재현 횟수 | 그런 창의 개수. 자기 자신과 ±L 이내 인접 창은 제외 |
| 유효성 | 활성 셀이 `max(3, 0.08·L·K)` 미만인 창은 후보에서 배제 (빈 창은 모티브가 아니다) |

hibari 는 phase-shifting 반복곡이므로, "가장 자주 되풀이되는 위상적 몸짓"이라는 정의가
곡의 성격과 직접 맞물린다. 곡이 스스로 강조한 것을 우리가 다시 강조하는 셈이다.

### 3.1 다양성 선별 — 세 조건

재현 횟수 상위를 그냥 n개 뽑으면 t=952 / t=950 처럼 **사실상 같은 모티브**가 뽑힌다.
그러면 "다른 모티브 → 다른 음악"이라는 검증 자체가 성립하지 않는다.
그래서 greedy maximin 으로, 이미 고른 것과 아래 셋 중 **하나라도** 걸리면 버린다.

| # | 조건 | 무엇을 막는가 |
|---|---|---|
| 1 | 시작 시점 차이 `< 4L` | 시간상 겹치거나 붙어 있는 창 |
| 2 | 패치 셀 일치율 `≥ 0.80` | 위치는 달라도 내용이 거의 같은 창 |
| 3 | 사용 cycle 집합의 Jaccard `≥ 0.60` | 패턴은 달라 보여도 **같은 cycle 들만 쓰는** 창 |

세 번째가 위상적으로 중요하다. 셀 배치가 달라도 쓰는 cycle 집합이 같으면
Algorithm 1 이 고르는 note 풀이 같아져 결국 비슷한 음악이 된다.

### 3.2 합성 모티브 — 통제력의 진짜 시험

hibari 에서 뽑은 모티브는 모델의 사전분포와 원래 잘 맞는다. 그러니 잘 되는 게 당연할 수 있다.
그래서 **원곡이 거의 쓰지 않는 cycle 조합**으로 만든 모티브를 대조군으로 하나 더 넣는다
(`synthetic_motif`, 두 스텝마다 점멸하는 `pulse` 패턴).

낯선 모티브를 줘도 보존되는가 — 이것이 "통제되는가"의 진짜 질문이다.
모델이 자기가 좋아하는 것만 지킨다면 그건 통제가 아니라 우연한 일치다.

## 4. 통제의 세 축

| 축 | 무엇을 정하는가 | 코드 | 음악적 의미 |
|---|---|---|---|
| **무엇을** | 모티브 패치 자체 | `extract_central_motifs` / `synthetic_motif` | 재료가 바뀌면 음악이 바뀐다 |
| **어디에** | 배치 위치 목록 | `PLACEMENTS` | 되풀이가 **형식**을 만든다 (론도·오스티나토) |
| **얼마나** | 마스크가 덮는 비율 | `PLACEMENTS` vs `PLACEMENTS_SPARSE` | 통제 강도 ↔ 변주 자유도 |

기본 배치는 32스텝(=4마디)마다, 즉 시간의 26.7%를 고정한다.
hibari 자체가 phase-shifting 반복곡이므로 오스티나토식 배치가 양식적으로도 맞다.
대조 배치는 64스텝마다(13.3%)로, **같은 모티브·같은 모델에서 마스크 폭만 바꾼** 비교다.

이 세 축은 모두 **샘플링 시점의 인자**다. 어느 것을 바꿔도 재학습이 없다.

## 5. 검증 지표

통제됐다는 주장은 두 방향으로 동시에 증명해야 한다 —
준 것은 살아남았고(①), 안 준 곳은 자유로우며(②), 다른 모티브는 다른 결과를 냈다(③).

### 5.1 motif_fidelity — 준 것이 살아남았는가

$$\mathrm{fid} \;=\; \frac{1}{|m|}\sum_{(t,c)\,:\,m_{tc}=1} \mathbb{1}\big[\,\mathbb{1}[\hat x_{tc}\ge\tau] = x^{\text{motif}}_{tc}\,\big],
\qquad \tau = 0.5$$

생성 결과를 학습 데이터와 **같은 자**(τ=0.5)로 이진화한 뒤, 마스크 영역에서의 셀 일치율.
1에 가까울수록 모티브가 그대로 남았다는 뜻.

> 이 지표가 1.0 이 아닐 수 있는 이유: RePaint 는 마지막 스텝(i=0)에서 마스크 영역에
> 원본을 넣지만, 그 값은 [-1,1] 공간의 연속값이고 τ 이진화는 그 뒤에 온다.
> 융합·클램프를 거치며 경계 셀이 τ 근처로 밀릴 수 있다.

### 5.2 free_region_difference — 통제가 복제가 아님

$$\mathrm{diff} \;=\; \underset{i<j}{\mathrm{mean}}\;\;
\underset{(t,c)\,:\,m_{tc}=0}{\mathrm{mean}}\; \mathbb{1}\big[\hat x^{(i)}_{tc} \neq \hat x^{(j)}_{tc}\big]$$

같은 모티브·같은 마스크에서 시드만 바꿔 뽑은 변주들 사이의, **마스크 밖** 셀 불일치 비율.
0에 가까우면 통제가 아니라 결정론적 복제다. **높을수록 좋다** — 단 §5.1과 함께 볼 때만.

두 지표는 짝으로 읽어야 한다.

| fidelity | free diff | 해석 |
|---|---|---|
| 높음 | 높음 | ★ 통제 성공 — 준 것은 지키고 나머지는 자유 |
| 높음 | 낮음 | 복제. 모델이 사실상 한 답만 낸다 |
| 낮음 | 높음 | 통제 실패. 그냥 무조건부 생성 |
| 낮음 | 낮음 | 모델 붕괴 |

### 5.3 cross-motif profile JS — 모티브가 결과를 갈랐는가

각 모티브의 변주 묶음에서 **cycle별 평균 활성 프로파일** $p \in \mathbb{R}^{K}$ 를 구하고
(`per_cycle_activation_profile`: 시간축·변주축 평균), 모티브 쌍마다 Jensen–Shannon divergence 를 잰다.

$$\mathrm{JS}(p_A, p_B) = \tfrac12 \mathrm{KL}(p_A \| \tfrac{p_A+p_B}{2}) + \tfrac12 \mathrm{KL}(p_B \| \tfrac{p_A+p_B}{2})$$

**클수록** 통제가 결과를 갈랐다는 뜻이다.
선행 negative 실험(`project_om_diffusion_negative_0621`)에서 MLP-DDPM 은 모든 cycle 프로파일이
거의 정확히 0.5 로 균질화됐다 — 즉 이 지표가 0 에 붙는 것이 실패의 서명이었다.
같은 지표를 조건부 축에서 다시 쓰는 셈이다.

### 5.4 보조 — 구조가 무너지지 않았는가

조건을 강제하면 자유영역의 통계가 망가질 수 있다. 아래 셋을 함께 기록한다.

| 지표 | 함수 | 확인하는 것 |
|---|---|---|
| 스텝당 밀도 | — | 과밀·과소 (선행 실패의 주 증상) |
| 시간축 autocorr | `temporal_autocorr` | 인접 시점 연속성 |
| cycle당 H₀ 활성구간 수·평균 길이 | `h0_runs_np` | 위상 손실이 겨냥한 바로 그 양 |

### 5.5 음악화 — 두 단 선별

OM 은 음악이 아니다. 트랙마다 Algorithm 1 후보를 뽑고 2단으로 거른다.

1. **구조 게이트** — 원곡과의 음고분포 JS 가 후보 중앙값 이하인 것만 통과
2. **미적 랭킹** — 통과한 것 중 **협화도** 최대

협화도만 쓰는 근거는 `project_aesthetic_rerank_negative_0613` 이다(합성 미적 지표는 calibration 실패,
성분 중 협화도만 유효). NodePool 온도 {1.0, 2.0, 3.0, 4.0} 로 후보 공간을 넓히고 랭킹이 고르게 한다.

### 6.2 통제가 됐는가

| 모티브 | 모티브 보존 | 자유영역 변주간 차이 | 밀도/스텝 | autocorr | 고리당 구간 |

- **보존 100.0% — 예외 없음.** 합성 모티브 D 도 hibari 유래 모티브와 똑같이 지켜졌다.
  RePaint 의 덮어쓰기가 조건을 *근사*하는 게 아니라 *강제*하기 때문이다.
- 자유영역은 6.2~14.8% 씩 달라진다 → **통제 ≠ 복제**. 준 곳은 고정, 안 준 곳은 자유.
- B 의 변주 폭이 가장 좁다(6.2%). B 는 14셀을 8개 cycle 에 퍼뜨려 심으므로
  남는 자유도가 작다 — 모티브가 넓게 퍼질수록 변주가 줄어든다.
- autocorr 0.849~0.868 (원곡 0.814). 조건을 걸어도 시간 구조는 무너지지 않았다.

| 32스텝마다 (8회) | 26.7% | 100.0% | **17.0%** |

§7 에 "마스크가 넓을수록 통제↑ 자유도↓"라고 적어 두었는데, **측정은 그렇지 않았다.**
고정 비율을 두 배로 늘려도 자유영역의 변주 폭은 16.5% → 17.0% 로 사실상 불변이다.
통제는 자유도를 **억누르지 않고 더한다** — 고정한 곳이 늘 뿐, 남은 곳의 다양성은
그대로다. (다만 §6.2 에서 보듯 모티브가 *여러 cycle 에 퍼지면* 변주 폭이 줄어든다.
즉 중요한 변수는 "얼마나 넓게 고정하는가"가 아니라 "몇 개의 고리를 묶는가"였다.)

## 7. 한계와 열린 문제

1. **마스크가 넓을수록 통제↑ 자유도↓.**
   이 트레이드오프는 방법의 결함이 아니라 정의 그 자체다. 다만 **어디가 무릎인지**는 모른다 —
   현재 실험은 13.3% / 26.7% 두 점만 재고, 그 사이의 곡선은 측정하지 않는다.

2. **모티브 자리는 사용자가 정한다.**
   `PLACEMENTS` 는 등간격 오스티나토로 손으로 박아 넣은 값이다.
   "어디에 놓아야 좋은가"를 곡에서 학습하는 절차는 없다.

3. **저노이즈 국소 조화의 한계.**
   jump 는 마스크 경계를 매끄럽게 하지만, 조건이 **전역적으로 불가능한 경우**
   (예: 모델 사전분포에서 밀도가 극히 낮은 cycle 조합을 곡 내내 강제) 를 해결하진 못한다.
   합성 모티브 D 가 이 경계를 시험한다.

4. **위상 손실은 학습에만 있고 샘플링에는 없다.**
   조건부 생성 중에 H₀ persistence 를 다시 강제하는 guidance 는 넣지 않았다.
   `topo_diffusion_report.md` §2.2 의 폐형식은 O(T)·미분가능이므로 원리적으로는 가능하다 — 미탐색.

5. **통제의 대상은 OM 이지 음표가 아니다.**
   OM→음악은 Algorithm 1 의 확률적 샘플링을 거치므로, 같은 모티브가 항상 같은 음형으로 들리지는 않는다.
   "위상적 몸짓의 통제"와 "선율의 통제"는 다른 층위다.

6. **평가에 사람이 없다.**
   §5 는 전부 계산 지표다. "모티브가 들리는가"는 청취 실험(Task 46 계열)의 몫이며,
   `skeleton` 트랙을 함께 렌더하는 이유가 그 준비다.

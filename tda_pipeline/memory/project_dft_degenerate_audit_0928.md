# DFT 거리 해석 감사 (2026-09-28)

## 사실
- `musical_metrics._build_dft_cache` 는 음높이 류 하나를 원-핫 12차원으로 FFT 해 **크기** |f̂(k)|, k=1..6 을 쓴다.
  한 점짜리 신호의 푸리에 계수 크기는 모든 k·모든 음높이 류에서 1 → 12행이 **바이트 단위로 같다** `[1,1,1,1,1,1]`.
- 이유: |DFT| 는 **전조 불변량**이다(전조는 위상만 돌리고 크기는 그대로 둔다). 단일 음들은 서로의 전조이므로
  전조 불변량으로는 원리적으로 구별되지 않는다. 곡과 무관하다 — 7-PC 곡이든 12-PC 곡이든 똑같이 0.
- 그래서 `dft_note_distance` = `0.3·|옥타브 차| + 1.0·|길이 차|/max 길이` (DFT 항 ≡ 0.0, 근삿값이 아니라 정확히).

## 대조 실험 — `experiments/run_dft_degenerate_control.py` → `docs/step3_data/dft_degenerate_control.json`
`build_overlap_bundle` 경로 그대로, "옥타브·길이만" 함수를 METRICS 등록부에 추가해(거리 함수는 수정 안 함) 비교.
- P1 음악거리 행렬 비트 동일 · P2 번들 안 바코드 **입력 151/151** · P3 **출력 151/151** · P4 고리·활성도·OM 동일
- P5 헤드라인 Algo1 JS 20개 동일 (0.009023, 기록 all_js 와도 최대 차 0)
- 양성 대조 C1 (dw 1.0 → 0.99): 바코드 입력·출력 **0/151** 동일 — 비교가 "같다" 를 거저 내주지 않는다
→ **헤드라인 JS=0.00902 는 DFT 가 전혀 없는 "옥타브·길이 + 빈도 하이브리드" 로 비트 단위 재현된다.**

## 이미 알려져 있었나 — 반쯤
- `project_metric_axiom_verification.md:41` (2026-04-18) 가 "같은 octave/duration 의 서로 다른 pitch class 쌍에서
  0거리 → 동일성 깨짐" 을 **이미 적었다**. 논문 §2 (full.md:234) 도 "동일한 magnitude spectrum 을 **가질 수 있다**" 고 썼다.
- 그러나 "거리 공리 위반" 이라는 **작은 기술적 흠**으로 분류됐고, "그러니 DFT 항은 아무 일도 안 한다" 는 결론으로
  이어지지 않았다. 같은 문서들이 계속 "DFT 가 스펙트럼·온음계 구조를 포착한다" 고 해석했다.
- 사용자는 2026-04-11 ~ 04-19 피드백에서 이 해석 문장들에 대해 **"스펙트럼 구조가 뭐야?"·"이해가 안 돼"** 를
  여러 번 물었다. 답변은 음 **집합** DFT 이론(Quinn·Amiot, C major 의 |F5|=2.73)으로 설명했는데 코드는
  **단일 음** DFT 였다 — 이해가 안 된 게 당연했다.

## 해석 문장 계열 (정정은 커밋 메시지에 파일:줄 목록으로)
가. 정의·계산 서술 — "Fourier 공간 L2", "치역 [0,√2]", C4-E4 계산 예시 (구현상 치역은 {0})
나. 결과 해석 — "DFT 가 스펙트럼/온음계 구조를 포착해서 우수", k=5 circle of fifths, Quinn(2007)
다. w_d=1.0 최적 해석 — 실제로는 음악거리에 남은 정보가 옥타브·길이뿐이라 길이를 줄이면 쪼그라든다
라. α=0 퇴화 = maximal evenness — 실제로는 음악거리 값이 14종뿐이라 동점이 많아서
마. 12-PC 곡의 DFT 분해능 — indicator (1,…,1) 논리는 집합 DFT 에 대한 것이라 해당 없음
바. 파생 해석 — 감쇄 lag×DFT(이미 T15 로 철회된 효과), complex×DFT, "구조 정밀도엔 DFT" 메타 통찰

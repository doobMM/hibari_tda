2026-10-01 흐름 (사용자 말 순서):
1. "맨 처음에 automata랑 같이 그려주었던 lenia처럼 음악을 … 게임과 결합 … TDA와 결합할 수 있어?" (= 09-28 오토마타 시안 보드의 C·F)
2. 시연 위젯 1 → "너무 정신이 없는데?" (판이 이끼처럼 차서 원 수십 개) → 오비움 두 마리 고요판 → "일단 나쁘지 않아" + "그게 H1이야? Tonnetz 면 고리가 한정되지 않아?"
   - 답: 판의 H1 = 생명체 모양의 구멍(무한정) · 지도 고리는 한정(12음 토러스 b1=2, 흰 건반 7음 b1=1 — 계산 확인).
3. "1번(hibari 자신의 지도)으로 하고 깊이로 세기 … hibari 는 착안점일 뿐, 더 많은 음악 … 고리가 유동적이거나 이용자가 변경"

지은 것: `sketch/lifeloop.html` + `lifeloop-core.js` + `tools/verify_lifeloop.mjs`(판정기 13개 통과).
- 생명체 = 오비움(Chan 2019) 0.7배, 64 토러스.
- 지도 = 음 17개(정본 PH 골격 배치). 고리 = 정본 14개 + 내 고리(먼저 운다).
- 구멍을 감싼 고리가 그 고리를 연주한다. 세기 = 구멍 깊이.

Lenia 사실:
- 벽 있는 판에서는 오비움이 죽는다. 무작위 씨앗은 판을 채우고, 매끈한 씨앗은 죽는다.
- 줄인 모양을 돌리며 줄이면 180° 쪽이 죽는다. 엇갈린 두 마리는 부딪혀 죽는다.
- 몸에 구멍을 내면 12번 중 8번 죽는다.

소리 규칙 네 번(같은 판 두 갈래, 생명체 움직임 동일):
1. 교집합: 0/120박
2. 가장 안쪽 고리: 1/7박
3. 내 고리 먼저 + 가까운 음: 0/7박 — 자리가 소리를 정했다
4. 고리 연주: 7/7박

450박 측정:
- 음이 난 박 97%.
- 고리가 켜진 박 19% — 예측 >30% 실패, 고치지 않음.
- 고리 13/14 켜짐, 음높이 17/17.

**Why:** 사용자는 Lenia 의 모양 + 게임 + TDA, 그리고 바꿀 수 있는 고리를 원했다. 고리가 소리를 정한다는 말은 같은 판 두 갈래로 재기 전에는 거짓이었다(세 번).

**How to apply:**
- 판정이 오면 CLAUDE.md 거절표·섹션을 고친다.
- 다음 후보:
  - 지도를 판 전체로 넓혀 고리가 켜지는 시간 늘리기(조정 후 재측정임을 밝힌다)
  - 생명체 수 늘리기와 충돌
  - 음 옮기기(고리 모양 바꾸기)
- 가려진 창에선 그리기 루프가 멈춘다 → `__sk.advance(sec)` 로 감는다.
- 엔진 주소는 `lifeloop-core.js?v=N` 으로 판을 올린다(캐시).

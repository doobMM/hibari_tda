2026-10-07 판 21: 날갯짓·큐브 둘 다 "직관적이지 않아서 별로" → "이전에 첨부했던 이미지 중에서 왼쪽에 있는 버전으로 … 원이 돌아가면서 나는 소리가 달라지는 거야".

사실:
- 세 무리 × 원 셋, 무리가 다른 원끼리 두 점에서 만나면 점 54 = 큐브 스티커 = hibari 한 모듈(59 − 공유 베이스 5). 원마다 점 12, 점마다 원 둘 = 큐브의 띠 짜임. 무리마다 n 개면 6n² — n = 3 만 hibari 에 맞는다.
- 사용자 그림은 동심원 도식이 아니라 큐브를 공으로 부풀려 뒤쪽 모서리에서 편 그림(가운데 육각 = 보이는 세 면, 바깥 꽃잎 = 숨은 세 면). 동심원으로 먼저 그렸다가 가운데가 비어 그림과 달라 고쳤다 — **참고 그림은 그리기 전에 다시 본다.**
- 판 = 공 위 진짜 원(띠 12칸이 한 평면) + 입체 사영 + 2·atan 압축. 돌리기 = 그 원 위 점 12개만(헝가리 고리), 사분에 멈춤, 상태는 놓는 순간.
- 칸표·소리·사건은 sketch/cube-core.js 의 create(H) 재사용(기하와 무관). 자리 순서만 F R U L D B(미 파 솔 라 시 도)로 — 빛이 가운데 한 바퀴, 바깥 한 바퀴.
- 판정기 tools/verify_rings.mjs R1–R12 PASS: 맞춘 판 1056/1056 두 손 · 원 9개 모두 들림(스텝 3~13) · 끌기 판정 108/108 · 무작위 300수 되돌리기 · → = 화면 시계 108/108 · 키 차례.
- 교훈: 그림 갱신(rAF)에 상태 변경을 걸면 가려진 창에서 확정이 안 된다 → 상태는 입력 순간, 그림은 뒤따라.

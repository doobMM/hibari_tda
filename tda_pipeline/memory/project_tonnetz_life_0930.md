## 페이지
- `lenia/life.html` (엔진 `lenia/life-core.js` — 페이지와 검증이 같은 파일). 2판 판정("음악은 듣기 좋아 / 오토마타 형식이 아니야 /
  피로를 세게 / 키보드로 더") 뒤에 지었다.
- 고운 격자 256×128 위 Lenia 오비움 = 생명체(두 손: 종달새·문어). Tonnetz 288칸은 그 위의 **음 지도**(고운 칸 → Tonnetz 칸 → hibari 음).
- 조작: ←↑→↓ 종달새 · WASD 문어 몰기 · Z~M 도~시 부르기 · Q/E rate · 1/2 하나 더 · 누르기 놓기 · 끌기 먹이.
- 균형 = 몸이 지는 나이(늙으면 잿빛, 방치 ≈2~4분에 사그라짐), 강화 = 발견(켜진 고리가 바코드에 남는다).
- 비옥도(사용자의 intra + rate×inter 를 움직임에)는 **기본 끔(v3.2)** — 켜면 돌봄을 벌했다(과성장 죽음). intra·inter 는 rate → 바코드 → 소리로 닿는다.

## 결과 요약
- 몰기 먹힘(두 회차 p ≤ 0.00025, ±45° 91.3% / 72.5%). 돌봄 14/20·15/20 vs 방치 1/20·2/20 생존 — 사전 문턱은 두 회차 모두 못 넘었다.
- rate 의 음높이 효과(ρ −0.69, 귀무 예측이 틀렸다)는 생명체가 아니라 **바코드 계단 하나**다(적대적 검토, 명세 §10.11). 찾은 고리 수는 포화(동어반복).
- 비옥도 메커니즘: 부호만 맞고 판별 불가(Holm 0.064·0.077, 검정력 0.47·0.28), 격자 최댓값 정규화라 엄밀히 국소 아님, 대가로 생존 13/20(0 → 20/20).

## 하네스 결함 4건 (반복 위험)
1. 토러스 둘레 절반을 넘는 변위를 끝점 차로 재면 방향이 뒤집힌다 → 박마다 증분을 더한다.
2. 결정적 CA 에서 시드가 음 뽑기만 바꾸면 "20시드" 가 한 궤적이다(유사반복).
3. 몸 아래 더하는 성장 가산은 무엇이든(1회차 끌기 0.35, 2회차 비옥도 0.1) 속을 채워 무너뜨린다 — 돌봄이 돌봄을 벌하는 경로.
4. 탐색에서 매개변수를 고른 초기 조건으로 확증을 돌리면 안 된다. 각도만 옮겨선 부족했다(2.266 ≈ 5×1.7 로 1회차·탐색과 겹침) → 3회차부터 자리도 옮긴다.

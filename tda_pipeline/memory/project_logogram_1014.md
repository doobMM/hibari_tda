(한국 개봉 제목 『컨택트』 = Arrival 2016. 1997년 Contact 가 아니다.)

- 참고: Christopher Wolfram 라이브 코딩 저장소 WolframResearch/Arrival-Movie-Live-Coding(원형문자 펼치기·모양 비교·원형문자로 키운 CA, 그림 ScriptLogoJpegs) · FlxB2/arrival_logograms(파이썬·pillow, MIT 생성기). Wolfram 블로그 본문에는 기법 상세가 없다.
- 그림: tools/logogram_views.py → docs/figures/logogram_views.png. 각 = 박, 굵기 = 울리는 음 수, 바깥 촉수 = 선율·윗음, 안쪽 덩이 = 베이스.
- 자료 사실: 곡 전체 1089박을 한 고리로 → 처음과 끝이 맞닿는다(왼손 모듈 k 가 k+1 박 늦고 k=31 에서 한 모듈 밀려 다시 맞음). 두 손 같은 박 같은 음 176번 중 44번이 반 모듈(16박) 어긋난 모듈 하나에 — 2구절 화음 = 1구절(미파솔라).
- 추천: 다(맞히기 — 들려준 변주를 귀로 듣고 같게 쓰기) 위에 가(쓰기), 나는 끝 화면. 위험: 원 위 32박은 판 14·18 에서 거절 — 잉크 모양이 곧 악보 · 목표와 사건 · 손짓이 곧 붓이어야 재포장이 아니다.

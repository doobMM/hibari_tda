- 자료 사실: 곡 전체 1089박을 한 고리로 → 처음과 끝이 맞닿는다(왼손 모듈 k 가 k+1 박 늦고 k=31 에서 한 모듈 밀려 다시 맞음). 두 손 같은 박 같은 음 176번 중 44번이 반 모듈(16박) 어긋난 모듈 하나에 — 2구절 화음 = 1구절(미파솔라).

- SIA 옮김 세기 조옮김 몫: hibari 0% · aqua 41%(+12, −4) · energy flow 49%(−2 반복) · 우연 대조 없음.
- 제안 문법: 낱말 = 동기 획, 문장 = 낱말 + 옮김(COSIATEC), 옮김 ↔ 그림 움직임 군 준동형, 손짓 = 군 원소, 되돌리기 = 역원. 다음 = COSIATEC 분해 그림(사용자 진행 여부 대기).
- 반지름 = 음높이 산점 그림은 동심 점선이라 버렸다.

# 곡의 모양 — 곡 하나를 3차원 몸 하나로 (2026-09-30)

사용자 요청(그대로): "ryuichi sakamoto를 포함해서 지금 midi 파일이 있는 곡들의 본질을 포착해서 단일한 3차원 모양으로 표현할 수 있으면 좋겠어."
참고: 조각 같은 덩어리 스크린샷 6장 + Matrix-3D · OrigamiSimulator · differential-line · WebGL-Fluid · particle-life · MarkovJunior.
전부: `docs/song_shape_notes.md` (모형 · 버린 시안 · 검사 표 · 한계).

## 무엇
- 페이지 `shape/index.html` (살 입히기 `shape/shape-core.js`, 자료 `shape/data/`). 13곡.
- 곡의 시간줄을 한 가닥으로 보고 **닮은 대목끼리 닿게 접는다**(`experiments/song_fold.py` → `export_song_shapes.py`). 단백질 접힘과 같은 꼴: 자기유사성 행렬 = 접촉 지도.
  색 = 5도권 방향, 굵기 = 지나간 횟수, 가닥 = 시간. 끌기·누르면 그 대목부터 듣기·펴기/접기·"다른 길로"(닮은 자리에서 건너뛰기).
- ⚠ 점은 **시각**이지 음이 아니다. 구멍 = 되돌아옴. 정본 PH 의 음 고리와 다른 대상(관계 미측정).

## 검사 (`experiments/run_song_shape_checks.py` → `song_shape_checks.json`, 예측은 실행 전에 적음)
- ✓ 시드 안정(되풀이 많은 6곡 거리 상관 ≥ 0.806) · ✓ 곡 구별(1-NN 0.973) · ✓ 맥락 길이·ρ·문턱 견고
- ✗ 시각 뒤섞기 문턱을 한 곡씩 넘음(emperor rec80 0.225, solari r 0.216) · ✗ 4박 도막 섞기(되풀이가 예상보다 많이 줆 — 대조군 설계가 나빴다: 도막이 맥락 창과 같은 길이)
- ✗ P5 hibari 자리바꿈 짝: 사전 기준(가장 닮은 시각 = 짝, 90%) 0.71. 사후 직접 측정으로는 합친 맥락에서 짝 자리 닮음 ≥ 0.95 가 78.7%, 성부를 가리면 0%.

## 발견 (탐색)
- hibari MIDI 는 두 성부가 0에서 같이 시작해 주기 32·33 으로 돌고 1056스텝 뒤 다시 만난다 = Piano Phase 와 같은 과정(한 바퀴의 위상 순환).
- 성부를 합쳐 들으면 모듈 a ≈ 모듈 33−a (지연 1056 − 65a). 순서 없는 두 점의 공간 = 뫼비우스 띠라는 해석은 **해석**이다(위상을 직접 재지 않았다).
- 기존 가중치 그래프는 "맥락 1스텝" 접기로 볼 수 있다(관찰, 식으로 보이지 않음).
- 버린 것: particle-life 그대로(종 = 음) → 곡이 구별 안 됨. 음의 그물(MDS) → 털뭉치.
